# matrix
## A mobile platform for building meaningful relationships. Capstone project.
*Connect. Share. Grow*

To be completes EST. Sunday evening.
Deadline for submission: Unknown

## Core Features
- User registration and login
- User profiles and interest selection
- Discover people with similar interests
- View other users' profiles
- Send and manage connection requests
- Manage existing connections

## Tech Stack
- React Native
- Expo
- JavaScript
- React Navigation
- (If Oladev can easily do a backend, let's do it)

## Getting Started
1. Clone the repository:
  `git clone https://github.com/laomgmg/matrix`
2. Enter the project directory:
   `cd matrix`
3. Install dependencies:
   `npm install`
4. Start the development server:
   `npx expo start`

## Team Collaboration
- Work on assigned features using separate Git branches.
- Use clear and descriptive commit messages.
- Test your changes before submitting them.
- Do not push directly to the `main` branch
- Communicate changes that may affect other team members
- Remember each of us should understand the codebase, so let's review each PR

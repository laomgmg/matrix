# Matrix

**Connect. Share. Grow.**

Matrix is a mobile platform designed to help people build meaningful relationships by discovering others with similar interests and connecting with them.

## Core Features

- User registration and authentication
- Personal profiles and interests
- Discover users with similar interests
- View other users' profiles
- Send and receive connection requests
- Manage connections and requests

## Technology Stack

- **Framework:** React Native
- **Platform:** Expo SDK 58
- **Language:** TypeScript
- **Navigation:** Expo Router
- **Package Manager:** npm

## Getting Started

### Prerequisites

Before getting started, install:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)
- [Expo Go](https://expo.dev/go) on your mobile device (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/laomgmg/matrix.git
   ```

2. Enter the project directory:

   ```bash
   cd matrix
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npx expo start
   ```

5. Scan the QR code with Expo Go or use an available emulator.

## Team Collaboration

To keep development organized:

1. Do not push directly to `main` during normal development.
2. Create a separate branch for each feature or task.
3. Use clear, descriptive commit messages.
4. Test your changes before opening a Pull Request.
5. Review and discuss Pull Requests before merging.
6. Communicate with the team when making changes that affect shared components or project structure.

## Development Workflow

Our planned application flow:

1. Authentication
2. User Profile
3. Discover
4. View Profile
5. Send Connection Request
6. Manage Connections
7. Accept or Reject Requests
8. View Connected Users
